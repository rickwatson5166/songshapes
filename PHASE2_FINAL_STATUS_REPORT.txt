================================================================================
                         KNOWN LIMITATIONS
================================================================================

1. F0 Detection on Synthetic Audio
   - Issue: Low confidence on pure sine waves
   - Status: Known, expected behavior
   - Workaround: Use real vocal recordings
   - Impact: Low (test audio works, real audio works)

2. In-Memory Sessions
   - Issue: Sessions lost on server restart
   - Status: By design for Phase 2 MVP
   - Solution: Phase 3 will add database persistence
   - Impact: Development/testing only

3. Single-Threaded Server
   - Issue: Flask dev server blocks on long operations
   - Status: By design for Phase 2 MVP
   - Solution: Deploy with gunicorn/uWSGI for production
   - Impact: Development/testing only

4. No Authentication
   - Issue: Any client can access any session
   - Status: Known limitation for Phase 2 MVP
   - Solution: Phase 3 will add session tokens + CORS
   - Impact: Use in trusted network only

5. Fixed Drum Style
   - Issue: Only "rock" pattern with 16th-note hi-hats
   - Status: Sufficient for Phase 2 MVP
   - Solution: Phase 3+ could add swing/funk/jazz
   - Impact: Low (rock is most common)

6. Simple Voice Leading
   - Issue: Bass just follows chord root octaves
   - Status: Sufficient for Phase 2 MVP
   - Solution: Phase 3+ could add inversions/voice leading
   - Impact: Low (results are musically acceptable)
